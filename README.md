# WEB TYCOON — Pirate Syndicate

**Browser idle / management game.** Build a network of websites, buy domains and servers, choose niches from legal blogs to gray and black ops, manage ban risk, staff, research, and sell mature projects on the market.

> Single HTML file. No install. No backend. Just open and play.

**[▶ Play on GitHub Pages](./index.html)** · Language: **Русский**

---

## О игре

Ты — основатель синдиката. Покупаешь домены, арендуешь серверы, деплоишь сайты в разных нишах и монетизируешь трафик. Чем агрессивнее схема — тем выше доход и **угроза бана**. Спасайся зеркалами, WAF, bulletproof-хостингом, юристами и honeypot-сайтами.

Жанр: **idle tycoon + risk management** с лёгким rogue-элементом (баны, события, тёмный форум).

## Возможности (v5.2)

### Инфраструктура
- 70+ доменных зон (`.com`, `.ru`, `.ai`, `.onion`, `.xyz` …)
- Серверы от Shared до Bulletproof Dedicated + **апгрейды** CPU/RAM/NET и **Anycast**
- Custom NS/DNS, WAF, свой email

### Сайты и продукт
- 35+ ниш: legal / gray / black
- Типы проектов: обычный сайт, **SaaS**, **мобильное приложение**, **honeypot**
- Плагины (SEO, антибот, антисниффер, AMP…)
- Контент, локали/переводы, легенды и обвесы
- Поддомены, сети сайтов, закрепление карточек

### Экономика и риск
- Монетизация от AdSense до scam/miner и **своей AdNet**
- Угроза бана, зеркала, ложные зеркала, авто-генерация зеркала
- Whitelist-путь для «белой» игры
- Биржа: продажа доменов и сайтов, **аукцион**, **M&A**
- **Тёмный форум** (лоты, риск скама)

### Мета
- Команда (SEO, юрист, grey-hat…)
- Дерево исследований
- Титулы и достижения
- Случайные события
- 6 тем оформления, 4 сложности
- **3 слота** сохранений + **песочница**
- Экспорт / импорт JSON

## Как запустить

### Локально
1. Скачай `index.html` (или `wt.html`)
2. Открой в браузере (Chrome, Firefox, Safari, Edge)

### GitHub Pages
1. Создай репозиторий
2. Залей `index.html` в корень (файл игры должен называться **`index.html`**)
3. Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)`
4. Через 1–2 минуты игра будет доступна по адресу:
   `https://<username>.github.io/<repo>/`

> Если файл сейчас называется `wt.html`, переименуй его в `index.html` перед деплоем.
